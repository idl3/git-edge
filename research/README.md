# Research

Engineer-level notes for git-edge: measured platform facts, the Rust/gitoxide check, and the idea proofs and reviews.

## Layout

| Path | What it is |
| --- | --- |
| `platform-facts.md` | Answers from a small test program on the real runtime |
| `rust-server.md` | Engineer memo: why the server is Rust + gitoxide |
| `rust-spike.md` | Spike notes for the Rust path |
| `proofs/` | **Canonical** second-pass proofs (Rust, against `CONTRACTS.md`) |
| `proofs/archived/` | First-pass TypeScript proofs (kept for history) |
| `reviews/` | **Canonical** second-pass reviews |
| `reviews/archived/` | First-pass reviews (kept for history) |

Wild ideas that never got a second pass live only under `proofs/archived/` and `reviews/archived/`. Prefer the canonical files when both exist.
